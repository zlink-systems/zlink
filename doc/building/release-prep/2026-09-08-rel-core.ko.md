# rel-core 공개 배포 준비 기록 (2026-09-08)

## 결과

Core 0.17.3의 ConanCenter 신규 recipe와 vcpkg 신규 port 제출 초안을 준비했다. 외부
registry 로그인, publish, PR 제출, commit과 push는 수행하지 않았다.

GitHub CLI는 인증 정보가 없어 릴리스 조회에 사용할 수 없었다. 공개 GitHub Releases API로
`core/v0.17.3` 자산을 조회했고, 별도 소스 자산
`zlink-0.17.3-source.tar.gz`가 있음을 확인해 Conan source로 우선 사용했다.

계산한 digest는 다음과 같다.

- 별도 소스 자산 SHA-256:
  `8ba9a1387dd4e97263cd7c61b8e98cd16b1132d528860d1d7254dbe69e6d14f0`
- 별도 소스 자산 SHA-512:
  `6b8354014c3f8594ff39c0df44df45c38f1a061bc09d04b8240b88b4cc20391e9d5ba3264bbfdf9bd477674cfc29ed3def179b55e2e379d9b9f71a9ef5a87021`
- GitHub 태그 자동 아카이브 SHA-256:
  `3e7a5111a445a69e04e3df901ee04ab9e1eedad4a0963ac73eb7535f277f5b94`
- GitHub 태그 자동 아카이브 SHA-512:
  `cdf4d4c4ecf1c15ea3856d4175b7bec6420c0feb5d2e82b4bf63a597bf187fba6aa4a0f09cad4745d387bd20f48a944b4a8bccaffa2cb6913eb50492e9a8f38c`

`vcpkg_from_github`는 릴리스 자산이 아니라 태그 자동 아카이브를 받으므로 vcpkg port에는
태그 자동 아카이브 SHA-512를 사용했다.

## 핵심 diff

- Conan `conandata.yml`에 별도 릴리스 소스 자산 URL과 SHA-256을 추가했다.
- Conan recipe에 C++17 검증, OpenSSL 의존성, shared/fPIC 정리, CMake layout과
  CMake/pkg-config target 정보를 추가했다. license, homepage, topics와 `package_type`도
  ConanCenter 형식에 맞췄다.
- Conan `test_package`는 공개 C API로 버전과 context 수명을 검사하며 shared target
  `libzlink`와 static target `libzlink-static`을 각각 소비한다.
- vcpkg overlay를 0.17.3으로 갱신하고 `vcpkg_from_github`, 계산한 SHA-512, 현행 CMake
  helper, OpenSSL, 정적/동적 linkage와 usage를 반영했다.
- ConanCenter 신규 recipe와 vcpkg 신규 port용 PR 본문 초안을 작성했다.
- `/tmp/zlink-codex-rel-core/conan-center-index/recipes/zlink/`와
  `/tmp/zlink-codex-rel-core/vcpkg/`에 공식 제출 구조를 만들고 형식을 확인했다. vcpkg
  version DB의 `git-tree`는 실제 제출 checkout에서 `vcpkg x-add-version zlink`로 생성해야
  하므로 임시 초안에는 생성 절차를 나타내는 자리표시자만 두었다. 임시 트리는 작업 완료 시
  삭제했다.

## 사용자가 직접 해야 할 일

이 작업에는 registry secret이 필요하지 않으며 참조하거나 생성한 secret 이름도 없다.

1. ConanCenter checkout에 `recipes/zlink/config.yml`과 저장소의
   `core/packaging/conan/{conanfile.py,conandata.yml,test_package/}`를 공식 구조로 복사한다.
2. `zlink-systems` GitHub 계정으로 CLA 상태를 확인하고
   `doc/building/pr-drafts/conan-center-0.17.3.md`를 사용해 draft PR을 연다.
3. vcpkg checkout에 `vcpkg/ports/zlink/`를 `ports/zlink/`로 복사한다.
4. vcpkg checkout에서 `vcpkg x-add-version zlink`를 실행해
   `versions/z-/zlink.json`의 실제 `git-tree`와 `versions/baseline.json` 항목을 생성한다.
5. 지원할 triplet에서 `vcpkg install zlink`를 실행한 뒤
   `doc/building/pr-drafts/vcpkg-0.17.3.md`의 테스트 플랫폼을 갱신하고 draft PR을 연다.

GitHub 인증은 PR을 여는 사용자가 대화형으로 수행해야 하며 token 값을 저장소 파일이나 로그에
기록하면 안 된다.

## 미해결 사항

- vcpkg 실제 install 검증과 공식 version DB의 `git-tree` 생성은 vcpkg checkout이 있는
  환경에서 남아 있다.
- ConanCenter와 vcpkg의 macOS·Windows 및 추가 compiler 조합은 각 upstream PR CI에서 확인해야
  한다.
- PR은 요청에 따라 제출하지 않았다.
