# ZLink .NET binding 0.17.7 release notes

Core remains 0.17.5. This .NET binding release is independently versioned as 0.17.7.

## Highlights

- NuGet publication metadata was updated for binding 0.17.7.
- The Windows local package build completed successfully. The .NET API has no new feature in this release.

## Installation

```bash
dotnet add package Zlink --version 0.17.7
```

The release tag is [`dotnet/v0.17.7`](https://github.com/zlink-systems/zlink/releases/tag/dotnet%2Fv0.17.7).
