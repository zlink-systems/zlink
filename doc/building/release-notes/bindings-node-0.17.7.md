# ZLink Node.js binding 0.17.7 release notes

Core remains 0.17.5. This Node.js binding release is independently versioned as 0.17.7.

## Highlights

- The published npm package and source build metadata were updated for this release.
- The Windows local package build completed successfully. No new Node.js API is introduced.

## Installation

```bash
npm install @zlink-systems/zlink@0.17.7
```

The release tag is [`node/v0.17.7`](https://github.com/zlink-systems/zlink/releases/tag/node%2Fv0.17.7).
