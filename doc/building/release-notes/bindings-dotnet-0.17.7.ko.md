# ZLink .NET binding 0.17.7 릴리스 노트

Core는 0.17.5로 유지됩니다. .NET binding은 독립적으로 버전 0.17.7을 사용합니다.

## 주요 변경

- binding 0.17.7에 맞춰 NuGet 게시 메타데이터를 갱신했습니다.
- Windows local package 빌드 성공을 확인했습니다. 이번 릴리스에서 .NET API 새 기능은 없습니다.

## 설치

```bash
dotnet add package Zlink --version 0.17.7
```

릴리스 태그는 [`dotnet/v0.17.7`](https://github.com/zlink-systems/zlink/releases/tag/dotnet%2Fv0.17.7)입니다.
