# ZLink C++ binding 0.17.7 릴리스 노트

Core는 0.17.5로 유지됩니다. C++ binding은 독립적으로 버전 0.17.7을 사용합니다.

## 주요 변경

- C++ source archive가 binding 빌드와 설치에 필요한 입력을 포함하도록 완결되었습니다.
- Windows local package 빌드 성공을 확인했습니다.

## 설치

[`cpp/v0.17.7` GitHub Release](https://github.com/zlink-systems/zlink/releases/tag/cpp%2Fv0.17.7)에서 `zlink-cpp-0.17.7.tar.gz`를 내려받거나, 0.17.7 Conan/vcpkg 패키지 메타데이터를 사용합니다.
