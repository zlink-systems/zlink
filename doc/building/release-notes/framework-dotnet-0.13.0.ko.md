# ZLink .NET Framework 0.13.0 릴리스 노트

Framework 0.13.0는 binding 1.1.0과 Core 1.1.0을 사용합니다. Framework 언어별 릴리스는 독립적으로 버전이 지정됩니다.

## 주요 변경

- 이 릴리스는 C++ 패키징 수정을 게시본에 담기 위해 냅니다. 사용자에게 보이는 API 변경은 없습니다.

## 설치

```bash
dotnet add package Zlink.Framework.AspNetCore --version 0.13.0
```

릴리스 태그는 [`framework-dotnet/v0.13.0`](https://github.com/zlink-systems/zlink/releases/tag/framework-dotnet%2Fv0.13.0)입니다.
