# ZLink C++ binding 1.4.0 release notes

This release aligns the C++ binding package with Core 1.4.0.

## Changes

- The C++ binding package version is 1.4.0 for the Core 1.4.0 release.
- No C++ binding source changes are included after 1.3.0; this release is version alignment for Core 1.4.0.

## Verification

- The release preflight verifies the C++ binding version, release notes, and Conan and vcpkg package metadata.

The release tag is `cpp/v1.4.0`.
