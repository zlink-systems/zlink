# ZLink Java Framework 0.11.1 release notes

Framework 0.11.1 uses binding 0.17.7 and Core 0.17.5. The Java framework release is independently versioned.

## Highlights

- Maven Central publication metadata was updated for framework 0.11.1.
- The Windows full build and representative standalone PowerShell run (Java Bingo) succeeded. No new Java framework API is introduced.

## Installation

```kotlin
implementation("systems.zlink:zlink-framework-core:0.11.1")
```

The release tag is [`framework-java/v0.11.1`](https://github.com/zlink-systems/zlink/releases/tag/framework-java%2Fv0.11.1).
