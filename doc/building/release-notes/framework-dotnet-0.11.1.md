# ZLink .NET Framework 0.11.1 release notes

Framework 0.11.1 uses binding 0.17.7 and Core 0.17.5. The .NET framework release is independently versioned.

## Highlights

- NuGet publication metadata was updated for framework 0.11.1.
- The Windows full build and representative standalone PowerShell run (.NET Bingo) succeeded. No new .NET framework API is introduced.

## Installation

```bash
dotnet add package Zlink.Framework.AspNetCore --version 0.11.1
```

The release tag is [`framework-dotnet/v0.11.1`](https://github.com/zlink-systems/zlink/releases/tag/framework-dotnet%2Fv0.11.1).
