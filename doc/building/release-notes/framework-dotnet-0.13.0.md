# ZLink .NET Framework 0.13.0 release notes

Framework 0.13.0 uses binding 1.1.0 and Core 1.1.0. Framework releases are versioned independently per language.

## Highlights

- This release exists to ship the C++ packaging fixes in a published artifact. No user-visible API changes.

## Installation

```bash
dotnet add package Zlink.Framework.AspNetCore --version 0.13.0
```

The release tag is [`framework-dotnet/v0.13.0`](https://github.com/zlink-systems/zlink/releases/tag/framework-dotnet%2Fv0.13.0).
