# ZLink Java binding 1.4.0 릴리스 노트

이 릴리스는 Java binding 패키지 버전을 Core 1.4.0에 맞춥니다.

## 변경

- Java binding 패키지 버전을 Core 1.4.0 릴리스에 맞춰 1.4.0으로 올립니다.
- 1.3.0 이후 Java binding 소스 변경은 없으며, 이 릴리스는 Core 1.4.0에 맞춘 버전 정렬입니다.

## 검증

- 릴리스 사전 검사는 Java binding 버전, 릴리스 노트, Maven 패키지 메타데이터를 확인합니다.

릴리스 태그는 `java/v1.4.0`입니다.
