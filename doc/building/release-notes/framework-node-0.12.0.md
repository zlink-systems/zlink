# ZLink Node.js Framework 0.12.0 release notes

Framework 0.12.0 uses binding 1.1.0 and Core 1.1.0. Framework releases are versioned independently per language.

## Highlights

- Moved to binding 1.1.0 and Core 1.1.0. The previous published release, 0.11.0, used binding 0.17.6.
- This release exists to verify the publication path and the installation procedure. User-visible changes are covered by the 0.20.0 release notes.

## Installation

```bash
npm install @zlink-systems/framework@0.12.0
```

The release tag is [`framework-node/v0.12.0`](https://github.com/zlink-systems/zlink/releases/tag/framework-node%2Fv0.12.0).
