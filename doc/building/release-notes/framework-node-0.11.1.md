# ZLink Node.js Framework 0.11.1 release notes

Framework 0.11.1 uses binding 0.17.7 and Core 0.17.5. The Node.js framework release is independently versioned.

## Highlights

- The framework package publication metadata was updated for 0.11.1.
- The Windows full build and representative standalone PowerShell run (Node.js TicTacToe) succeeded. No new Node.js framework API is introduced.

## Installation

```bash
npm install @zlink-systems/framework@0.11.1
```

The release tag is [`framework-node/v0.11.1`](https://github.com/zlink-systems/zlink/releases/tag/framework-node%2Fv0.11.1).
