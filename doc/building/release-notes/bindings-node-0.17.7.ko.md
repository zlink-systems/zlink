# ZLink Node.js binding 0.17.7 릴리스 노트

Core는 0.17.5로 유지됩니다. Node.js binding은 독립적으로 버전 0.17.7을 사용합니다.

## 주요 변경

- 이번 릴리스에 맞게 npm 패키지와 source build 메타데이터를 갱신했습니다.
- Windows local package 빌드 성공을 확인했습니다. 새로운 Node.js API는 추가하지 않았습니다.

## 설치

```bash
npm install @zlink-systems/zlink@0.17.7
```

릴리스 태그는 [`node/v0.17.7`](https://github.com/zlink-systems/zlink/releases/tag/node%2Fv0.17.7)입니다.
