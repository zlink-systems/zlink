# ZLink Node.js Framework 0.14.0 release notes

Framework 0.14.0 uses binding 1.1.0 and Core 1.1.0. Framework releases are versioned independently per language.

## Highlights

- This release exists to ship the C++ packaging fixes in a published artifact. No user-visible API changes.

## Installation

```bash
npm install @zlink-systems/framework@0.14.0
```

The release tag is [`framework-node/v0.14.0`](https://github.com/zlink-systems/zlink/releases/tag/framework-node%2Fv0.14.0).
