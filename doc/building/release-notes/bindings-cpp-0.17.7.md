# ZLink C++ binding 0.17.7 release notes

Core remains 0.17.5. This C++ binding release is independently versioned as 0.17.7.

## Highlights

- The C++ source archive is complete and includes the inputs required to build and install the binding.
- The Windows local package build completed successfully.

## Installation

Download `zlink-cpp-0.17.7.tar.gz` from the [`cpp/v0.17.7` GitHub Release](https://github.com/zlink-systems/zlink/releases/tag/cpp%2Fv0.17.7), or use the Conan/vcpkg package metadata for version 0.17.7.
