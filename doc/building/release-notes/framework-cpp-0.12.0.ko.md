# ZLink C++ Framework 0.12.0 릴리스 노트

Framework 0.12.0는 binding 1.1.0과 Core 1.1.0을 사용합니다. Framework 언어별 릴리스는 독립적으로 버전이 지정됩니다.

## 주요 변경

- binding 1.1.0과 Core 1.1.0을 사용하도록 올렸습니다. 직전 게시본 0.11.0은 binding 0.17.6을 사용했습니다.
- 이 릴리스는 배포 경로와 설치 절차를 확인하려고 냅니다. 사용자에게 보이는 변경은 0.20.0 릴리스 노트가 다룹니다.

## 설치

[`framework-cpp/v0.12.0` GitHub Release](https://github.com/zlink-systems/zlink/releases/tag/framework-cpp%2Fv0.12.0)에서 `zlink-framework-cpp-0.12.0.tar.gz`를 내려받고 `find_package(zlink_framework_cpp CONFIG REQUIRED)`를 사용합니다.
