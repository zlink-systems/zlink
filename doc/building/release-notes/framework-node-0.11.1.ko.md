# ZLink Node.js Framework 0.11.1 릴리스 노트

Framework 0.11.1은 binding 0.17.7과 Core 0.17.5를 사용합니다. Node.js framework 릴리스는 독립적으로 버전이 지정됩니다.

## 주요 변경

- 0.11.1에 맞춰 framework 패키지 게시 메타데이터를 갱신했습니다.
- Windows 전체 빌드와 대표 PowerShell 단독 실행(Node.js TicTacToe)이 성공했습니다. 새로운 Node.js framework API는 추가하지 않았습니다.

## 설치

```bash
npm install @zlink-systems/framework@0.11.1
```

릴리스 태그는 [`framework-node/v0.11.1`](https://github.com/zlink-systems/zlink/releases/tag/framework-node%2Fv0.11.1)입니다.
