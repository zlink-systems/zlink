# ZLink C++ Framework 0.11.1 release notes

Framework 0.11.1 uses binding 0.17.7 and Core 0.17.5. Framework language releases are independently versioned.

## Highlights

- The C++ framework standalone package was fixed so its published archive can be installed and used with the required runtime inputs.
- Windows full build and representative PowerShell runs succeeded: Release 28 targets/install, TicTacToe, and DeliveryDispatch.

## Installation

Download `zlink-framework-cpp-0.11.1.tar.gz` from the [`framework-cpp/v0.11.1` GitHub Release](https://github.com/zlink-systems/zlink/releases/tag/framework-cpp%2Fv0.11.1), then use `find_package(zlink_framework_cpp CONFIG REQUIRED)`.
