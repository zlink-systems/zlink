## 실행 조건

- 측정 호스트 cloudv 전용이다. 툴체인·Core·`run-one.sh` 경로가 cloudv 배치를 가정한다
- 모든 측정은 `run-one.sh`의 배타 잠금 안에서 순차로 돈다. `NOLOCK` 같은 잠금 우회는 쓰지 않는다
- 잠금 요청 직전과 러너 시작 직전에 1분 load < 12, MemAvailable ≥ 10 GiB를 확인한다
- 측정 중에는 같은 호스트에서 다른 무거운 작업을 돌리지 않는다
- 결과 디렉터리는 호출마다 새로 만들고 재사용하지 않는다
