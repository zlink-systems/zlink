# core 성능 개선 작업 로그

이 디렉토리는 `doc/plan/perf/core/core-library-performance-improvement-plan.ko.md`에 따라
진행한 core 성능 개선 라운드의 작업 기록을 보관한다.

각 라운드는 goal 하나와 로그 파일 하나를 기준으로 진행한다. 로그에는 기준 report,
가설, 읽은 코드, 변경, 검증, 결과, 다음 작업을 적는다.

파일명 형식:

```text
YYYY-MM-DD-round-N-short-topic.ko.md
```

perf 전용 변경이나 측정 조건 변경으로 얻은 수치는 core 성능 개선 결과로 기록하지 않는다.
