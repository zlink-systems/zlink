## spec-gap 후보

이번 재작성에서는 규칙을 옮기기만 했고 스펙 오류·개선은 판단하지 않았다. 아래는 재작성
중 발견했으나 이 문서가 해소할 수 없는 항목이다. 코디네이터 판정 대상.

- **R128 값 미정(구조 후보 아님, 참고)** — `29-transport-liveness §4`의 수신 상한 3축(건수·byte·
  경과 시간) 값이 아직 정해지지 않았다. `05-transport-liveness.ko.md`(다른 에이전트 작업물)
  쪽 관할이라 이 대장에는 옮기지 않았지만, 두 문서(R49 가중 라운드로빈 선택과 §8의 receive-flow
  상한)가 같은 "무한정 읽지 않는다" 원칙을 공유하므로 그쪽 판정 시 이 문서의 selector 설명과
  충돌하지 않는지 확인이 필요하다.
- **구조 후보 — 08 §3.2 소제목 승격(S6)** — 처리 완료로 기록한다. 옛 문서에서 "선택 순서"가
  `###`(3레벨)이라 `##` 목차에서 빠지고 코드 주석이 실제로 없는 절 번호(§3.2)를 인용하던
  문제를, 새 문서에서는 정식 top-level 절(§3)과 안정적인 명시 anchor
  (`#weighted-round-robin-selection-order`)로 해소했다. 코드 주석 갱신은 위 CODE CONSTRAINT
  표를 따른다.
- **매핑표 §3 표기 오타 확인** — 매핑표 §3은 `target-readme.ko.md`의 `05-transport-liveness`·
  `05-wire-protocol` 번호 중복 오타를 이미 `06-wire-protocol`로 정정해 썼다고 기록했다. 이
  문서 작성자는 target-readme.ko.md 자체를 수정하지 않았다(작업 범위 — 산출물 파일 3개
  외 수정 금지). 코디네이터가 정정할 항목으로 남긴다.
