## 흡수한 중복 위치

**S8** — 같은 규칙이 두 자리에서 서술되던 것을 한 곳으로 합쳤다.

- (a) 05 §1.1 "Yield 시 claim과 gate" + 05 §3 "Yield 시 gate와 claim" → `02` §3 한 곳(R5+R24
  통합). `01-submit-and-completion.ko.md`에는 이 규칙의 본문을 남기지 않고 §3 링크만
  두도록 요청했다(해당 문서는 다른 에이전트 소관이라 직접 확인은 못 함 — 리뷰 시 대조
  필요).
- (b) 05 §2 "같은 turn에서의 대기" + 41 §6 "기다릴 때 실행 권한 반납" → `02` §4 한 곳
  (R21+R128+R129+R130 통합).

**S9** — 42 §7의 owner당 두 FIFO(application/lifecycle) 분리 서술이 41 §2의 lane 표와
구조가 겹쳤다. 41(→ `02` §7)이 정확한 수치(1,024건·64 MiB, 128건·4 MiB, 10 ms, 8 turn)를
소유하는 유일한 자리로 남기고, `02` §13(application/infrastructure 절)에서는 "두 도메인은
owner마다 물리적으로 다른 FIFO로 분리된다"는 결과 한 문장만 쓰고 §7을 링크했다. 42 §7의
나머지 내용(R98·R100 — 실행 영역 문맥 표시·잘못된 조합 시 실패)은 FIFO 중복과 무관한
별도 규칙이라 §13에 그대로 남겼다.
