# Node.js 공개 interface 이동 안내

Node.js server package의 정확한 public TypeScript declaration은 범주별 문서로 나누어 관리한다.
전체 문서 목록은 [공개 인터페이스 목차](interfaces/README.ko.md)에서 확인한다.

- builder와 구성 option: [기초 타입과 구성](interfaces/01-foundation-configuration.ko.md)
- Channel·request·routing: [Channel, request와 routing](interfaces/02-channel-messaging.ko.md)
- Location·monitoring·metrics: [Location, monitoring과 metrics](interfaces/03-location-observability.ko.md)
- Spot과 Instance Spot: [Spot과 Instance Spot](interfaces/04-spots.ko.md)
- Actor와 session binding: [Actor와 session binding](interfaces/05-actors.ko.md)
- STREAM·timer·worker: [STREAM, timer와 worker](interfaces/06-stream-worker.ko.md)
- NestJS adapter: [NestJS host adapter](interfaces/07-nestjs-host.ko.md)
- Location·Relocation provider: [Location·Relocation provider](interfaces/08-location-maintenance.ko.md)

이 파일은 이 문서 주소를 사용하는 링크를 새 목차로 연결하기 위한 안내 문서다. 정확한 declaration은
위 범주별 문서만 소유한다.
