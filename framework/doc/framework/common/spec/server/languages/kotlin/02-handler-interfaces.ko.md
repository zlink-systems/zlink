# Kotlin handler interface 문서 위치

Kotlin coroutine handler, call extension과 generated JVM signature는
[exact interface 목차](interfaces/README.ko.md)에서 기능별로 제공한다.

- [Channel messaging](interfaces/channel-messaging.ko.md)
- [Spot](interfaces/spots.ko.md)
- [Actor](interfaces/actors.ko.md)
- [STREAM session](interfaces/stream-session.ko.md)
- [Monitoring](interfaces/monitoring.ko.md)

Kotlin은 Java factory configure callback에 연결된 relocation 동작을 재사용하며 별도 relocation registry를 추가하지 않는다.
