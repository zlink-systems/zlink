# 판정 노트 (plan §18 #8 escape clause):
# - throughput: legacy-inline 1,352,150/s -> unified-serial 147,264/s (-89.1%).
# - p95: legacy-inline 9.448us -> unified-serial 1,477us.
# - legacy-inline은 Entry Spot application callback을 직렬 gate에 태우지 않는 비교군이다.
#   200 caller thread가 handler를 직접 진행하므로 Entry Spot 공유 상태를 동시에 건드릴 수 있다.
# - unified-serial은 10,000 packet이 하나의 Entry Spot 실행 줄을 통과한다. per-packet
#   latency에는 큐 체류시간이 포함되고, throughput은 단일 실행 줄의 drain 속도를 측정한다.
# - 이 차이는 plan §1의 핵심 결정인 "Entry Spot application callback은 일반 Spot처럼
#   직렬 실행한다"를 적용한 구조적 비용이다. 이전 동작 대비 -10% throughput gate로
#   판정하지 않고, 직렬 실행 의미를 만족하는 상태에서 future baseline으로 사용한다.
