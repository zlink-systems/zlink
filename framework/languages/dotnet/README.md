# ZLink Framework for .NET

ZLink Framework packages provide the .NET server integration, HTTP client, and
STREAM connector for applications built on the `Systems.Zlink` binding.

The public release packages are:

- `Systems.Zlink.Framework.AspNetCore`
- `Systems.Zlink.HttpClient`
- `Systems.Zlink.Stream.Connector`

Documentation and source are available in the
[zlink repository](https://github.com/zlink-systems/zlink).
