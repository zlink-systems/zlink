# zlink-framework-locations-redis

이 package는 **Redis** plugin에서 두 Store를 각각 등록할 때와 **Redis with etcd** plugin에서 Redis Relocation Store를 등록할 때 사용한다. 설치와 두 등록 호출은 [Store plugin 설정](../../../doc/framework/java/guide/server/25-location.ko.md#store-setup)을 따른다. [Kotlin](../../../doc/framework/kotlin/guide/server/25-location.ko.md#store-setup)도 같은 Java package를 사용한다.
