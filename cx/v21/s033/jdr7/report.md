PR #4056의 Java service port close deadline을 주입할 수 있게 수정하였다. `ZLinkJavaRawServicePort`에 `private final Duration closeDeadline` 필드를 추가하고, `close()`가 이 값으로 close 호출의 단일 기한을 계산하게 하였다. 패키지 전용 생성자 `ZLinkJavaRawServicePort(Context, ZLinkStateLane, Duration)` 하나를 추가하였다. 기존 생성자들은 기본 종료 기한인 `DEFAULT_TERMINATION_DEADLINE`을 전달하며, private 생성자 경로도 같은 기본값으로 최종 생성자에 도달한다.

`failedSocketCloseRetainsOwnershipUntilLaterCleanupSucceeds`와 `meshExplicitCloseReachesRetainedSocketOwner`는 50ms 기한을 주입한다. 두 테스트는 BUSY 상태가 기한을 넘긴 뒤 실패가 반환되고 socket 소유권이 유지되는지 확인한 다음, BUSY를 해제해 다음 close가 정리하는지 확인한다. mesh 테스트는 재진입 호출이 두 번인지 확인한다. 응답과 close의 경합 테스트에서 허용 결과는 변경하지 않았다.

최종 contract suite는 255개 반복과 테스트 중 12개가 실패하여 Gradle이 실패로 끝났다. 실패 12개는 기존 reply/close 경합 assertion으로, port 경합 7개와 runtime 경합 5개이며 이 작업에서 허용 결과를 수정하지 않았다. Gradle 실행 시간은 2분 15초였고 JUnit suite time은 11.713초였다. 수정한 테스트의 JUnit 시간은 `failedSocketCloseRetainsOwnershipUntilLaterCleanupSucceeds` 0.052초, `meshExplicitCloseReachesRetainedSocketOwner` 0.128초, `busySocketCloseSucceedsWhenBusyClearsWithinTheCurrentCloseAttempt` 0.009초, `slowReplyAlreadySubmittingLeavesBeforeCloseSucceeds` 0.121초였다. 반복 경합 테스트 시간은 port 4.342초, runtime 3.497초였다.
